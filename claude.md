# Claude instructions

- All scripts must be POSIX compatible. And contain a --help flag that explains what the script does
- Focus on writing readable, maintainable and simple code.
- All variables should have self explanatory names.
- Don't add comments unless absolutely needed to explain unexpected behaviour or code.
- Don't use abreviations unless variable/file names would become way too long.
- Use conventional commits. Each commit should exactly add 1 feature or 1 fix bug.
- The information in the README.md must always be up to date.
- Always handle every error case
